# 3. Lung

- 우 4엽, 좌 2엽으로 총 6엽이다.
  ![[Pasted image 20241215043924.png|300]]
- 외측상은 겹쳐 보여 선호되지 않고, DV나 VD - 특히 **VD**가 선호된다.
	- DV : 안정된 자세, 기흉 촬영
	- VD : 흉수 촬영
	- 호흡곤란, 기흉 의심될 때는 DV 촬영 (자세 뒤집으면 힘들어함)


| Patterns                                                                                                        |     |
| --------------------------------------------------------------------------------------------------------------- | --- |
| **Bronchial pattern** (기관지 패턴)<br>염증 세포 침윤으로 기관지벽 두꺼워짐<br>- Doughnut sign : end-on<br>- Tramline sing : side-on |     |
| **원인**<br>- Bronchitis (만성)<br>- Allergic (<u>Feline asthma</u>, 알러지성 폐렴)<br>- Immune-mediated (PIE)            |     |
