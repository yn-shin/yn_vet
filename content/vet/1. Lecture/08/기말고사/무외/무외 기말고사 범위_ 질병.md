# Supraspinatus tendinopathy (가시위근 힘줄병증)

>[!note] Supraspinatus complex의 insertional tendon의 mineralization 또는 nonmineralization

(Mineralization : 석회화된(calcified) 물질의 축적)

|     |                                                                                                                                                                                                                                                                                                                                                                                       |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 병리  | - 원인은 정확히 밝혀지지 않았으나, aging, overuse, trauma, (hypovascularity에 의한) hypoxia 등으로 발생한다.<br>- 힘줄 퇴화의 특징으로서 Myxomatous degeneration, chondroid metaplasia이 같이 관찰될 수 있다.<br>- 심하면 mineral과 fibrous tissue의 mass가 biceps tendon을 밀어낼 수 있다.<br>- Biceps와 supraspinatus의 질병은 병발할 수 있고, supraspinatus가 두꺼워지면 biceps tendon을 대체하면서 염증과 통증을 유발할 수 있다.                                             |
| 진단  | - Greater tubercle의 ==medial== 측을 촉진하면 통증이 있고, ==shoulder flexion==과 ==elbow extension== 시 통증 반응이 커질 수 있다. <br>	- 정확한 검사 : flex shoulder first, then elbow extension.<br>- 가장 흔한 초음파 소견으로 tendon of insertion에서 enlargement가 관찰된다.<br>- 비대해진 supraspnatus tendon이 biceps tendon과 tendon sheath에 자극을 가하면 intertubercular groove에서 osteophytosis(골증식) 소견이 나타날 수 있으며, 이차성 관절염을 초래할 수 있다. |
| 치료  | - 보통 ==내과적 치료를 먼저 시도==하며, 듣지 않는 경우 수술적 치료가 지시된다.<br>- 내과적 치료 : glucocorticoid 주사와 휴식을 병행하여 일시적으로 완화될 수 있다. 반복 주사는 권장하지 않음.<br>- 수술적 치료 : 힘줄에서 mineralizaion된 부분 제거, 심한 경우 tendon 절개(resection), multiple longitudinal tenotomy (tendon 내부 압력을 줄이고, 혈관화를 증가시킴.)<br>- 수술 후 leash walking 정도로 8-10주간 활동을 제한한다.<br>- 예후는 ==좋은 편==이나, 다른 shoulder diseases의 존재에 따라 다를 수 있다.                |

# Infraspinatus fibrotic contraction (가시아래근 섬유성 수축)

>[!note] 정상적인 musle-tendon unit이 섬유 조직으로 대체되면서 발생하는 근육이나 힘줄의 기능적 단축

|     |                                                                                                                                                                                                                                                                                                                  |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 병리  | - 사냥개에서 가장 흔하고, 되돌릴 수 없는 근섬유 손상 이후에 나타난다.<br>- 원인은 명확히 밝혀지지 않았으나, 주로 근육 문제로 본다. 반복적인 미세 외상이나 과도한 운동으로 근섬유가 손상되면, 염증을 일으키고 결국 섬유화로 이어지는 것으로 알려져 있다.<br>- 손상된 근육 부위에서는 퇴행(degeneration), 위축(atrophy), 섬유형성(fibroplasia)가 관찰된다.                                                                                     |
| 진단  | - 어린 개체 또는 성체의 스포츠 견종에서 발생한다.<br>- 특징적인 보행 이상(gait abnormality)는 진행성 섬유화와 가시아래근 수축에 이어 발생한다. 근육이 짧아지면 어깨의 ==external rotation==이 유발되고, 팔꿈치의 ==abduction(외전)==과 발바닥의 ==outward rotation==이 나타난다.                                                                                                                  |
| 치료  | - Physical rehabilitation(물리 치료)는 조기에 실시될 경우 수축 예방에 큰 도움이 된다. <br>- 수축이 진행된 개에서는 ==수술적 치료가 가장 일반적==이고 성공적이다.<br>- 수술적 치료는 섬유화된 myotendinous infaspinatus muscle을 풀어주는 데 중점을 둔다.<br>- 수술 시 어깨 관절의 전외측(craniolateral)으로 접근하여, 섬유화된 근육과 섬유띠(fibrous bands)를 절단한다.<br>- 수술 후 치료는 특별히 필요하지 않으며, 며칠 후 다리를 사용할 수 있게 된다. |
